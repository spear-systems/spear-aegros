# Security policy

## Reporting vulnerabilities in Spear Aegros (the product)

Email or use your org’s **private vulnerability reporting** channel for the `spear-systems/spear-aegros` repository. Do not open public issues for undisclosed security defects.

Include: affected version, reproduction steps, impact assessment.

## “Security scanning” vs product security

This repository builds **tools that perform security assessments**. Misuse against systems without authorization is illegal and against project policy. See [docs/legal-safe-use.md](docs/legal-safe-use.md).
